1. INTRODUCTION                                         *luminate-introduction*

Luminate provides visual feedback for text operations in Neovim by
temporarily highlighting affected regions during:
  - Yank operations (via TextYankPost)
  - Paste operations (via custom keymaps)
  - Undo operations (via custom keymaps)
  - Redo operations (via custom keymaps)

The plugin helps you track where text changes occur, making it easier to
follow editing operations in your workflow.

==============================================================================
2. REQUIREMENTS                                         *luminate-requirements*

- Neovim >= 0.6.0
- Optional: A colorscheme that defines appropriate highlight groups

==============================================================================
3. SETUP                                                       *luminate-setup*

To use Luminate, call the setup function in your init.lua:
>lua
    require('luminate').setup({
      -- your configuration here
    })
<

For default configuration, simply call:
>lua
    require('luminate').setup()
<

==============================================================================
4. CONFIGURATION                                       *luminate-configuration*

The following options can be passed to setup():

                                                           *luminate.duration*
duration                (number, default: 500)
    Duration in milliseconds for the highlight to remain visible.

                                              *luminate.highlight_threshold*
highlight_threshold     (number, default: 0.9)
    Skip highlighting if the changed text exceeds this fraction of total
    buffer lines. Range: 0.0 to 1.0. This prevents highlighting large
    changes like file format operations.

                                              *luminate.highlight_for_count*
highlight_for_count     (boolean, default: true)
    When true, respects count prefixes for undo/redo operations.
    For example, "5u" will undo 5 times and highlight all changes.

                                                              *luminate.yank*
yank                    (table)
    Configuration for yank highlighting.
    Fields:
      - enabled  (boolean, default: true)  Enable yank highlighting
      - hlgroup  (string, default: "LuminateYank")  Highlight group name
      - guibg    (string, default: "#2d4f67")  GUI background color
      - fg       (string, default: "#ebcb8b")  Foreground color

                                                             *luminate.paste*
paste                   (table)
    Configuration for paste highlighting.
    Fields:
      - enabled  (boolean, default: true)  Enable paste highlighting
      - hlgroup  (string, default: "LuminatePaste")  Highlight group name
      - guibg    (string, default: "#2d4f67")  GUI background color
      - fg       (string, default: "#ebcb8b")  Foreground color
      - mode     (string, default: "n")  Mode for keymap
      - lhs      (table, default: {'p', 'P'})  Keybindings
      - map      (table, default: {p='p', P='P'})  Commands to execute
      - opts     (table, default: {})  Keymap options

                                                              *luminate.undo*
undo                    (table)
    Configuration for undo highlighting.
    Fields:
      - enabled  (boolean, default: true)  Enable undo highlighting
      - hlgroup  (string, default: "LuminateUndo")  Highlight group name
      - guibg    (string, default: "#2d4f67")  GUI background color
      - fg       (string, default: "#ebcb8b")  Foreground color
      - mode     (string, default: "n")  Mode for keymap
      - lhs      (table, default: {'u', 'U'})  Keybindings
      - map      (table, default: {u='u', U='U'})  Commands to execute
      - opts     (table, default: {})  Keymap options

                                                              *luminate.redo*
redo                    (table)
    Configuration for redo highlighting.
    Fields:
      - enabled  (boolean, default: true)  Enable redo highlighting
      - hlgroup  (string, default: "LuminateRedo")  Highlight group name
      - guibg    (string, default: "#2d4f67")  GUI background color
      - fg       (string, default: "#ebcb8b")  Foreground color
      - mode     (string, default: "n")  Mode for keymap
      - lhs      (table, default: {'<C-r>'})  Keybindings
      - map      (string, default: "<C-r>")  Command to execute
      - opts     (table, default: {})  Keymap options

Example configuration:
>lua
    require('luminate').setup({
      duration = 300,
      highlight_threshold = 0.8,
      yank = {
        enabled = true,
        guibg = '#ff0000',
      },
      paste = {
        enabled = true,
        lhs = { 'p', 'P', '<leader>p' },
        map = { p = 'p', P = 'P', ['<leader>p'] = '"+p' },
      },
      undo = {
        enabled = false,  -- Disable undo highlighting
      },
    })
<

5. HIGHLIGHT GROUPS                                       *luminate-highlights*

The following highlight groups are used by default:

LuminateYank                                                   *LuminateYank*
    Highlight group for yank operations.
    Default: guibg=#2d4f67 fg=#ebcb8b

LuminatePaste                                                 *LuminatePaste*
    Highlight group for paste operations.
    Default: guibg=#2d4f67 fg=#ebcb8b

LuminateUndo                                                   *LuminateUndo*
    Highlight group for undo operations.
    Default: guibg=#2d4f67 fg=#ebcb8b

LuminateRedo                                                   *LuminateRedo*
    Highlight group for redo operations.
    Default: guibg=#2d4f67 fg=#ebcb8b

You can customize these in your colorscheme or after setup:
>vim
    highlight LuminateYank guibg=#ff0000 guifg=#ffffff
<

==============================================================================
6. COMMANDS                                                 *luminate-commands*

Luminate does not provide user commands. It works through autocommands and
keymaps:

- Yank highlighting is triggered automatically via TextYankPost
- Paste/Undo/Redo highlighting is triggered via custom keymaps

To disable specific operations, set their `enabled` option to false in setup.
